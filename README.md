* [My Neocities page](https://fiveelementninja.neocities.org/) - A static site built with NextJS and deployed to Neocities. Currently just displays the last song I listened to on my Plex server. A Node script polls my local Tautulli server to get most recent song information from Plex, formats the data, and uploads it to my Neocities site for display on the page.
